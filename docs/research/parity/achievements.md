# Achievements / Trophies

Sources: cc-resource `Platforms/Achievements.md`; Steam list https://steamcommunity.com/stats/204360/achievements (12 achievements; Steam uses the Remastered set).

## Steam (12)
| Name | Condition |
|---|---|
| Animal Handler | Collect all the animal orbs |
| Arena Master | Win 40 Arena Online matches |
| Conscientious Objector | Complete Home Castle through Barbarian Boss areas without attacking any foes |
| Deer Trainer | Navigate the Abandoned Mill without hitting any obstacles |
| Kay Eye Ess Ess | Collect all 4 princesses' kisses in a multiplayer game |
| Maximum Firepower | Using a catapult, fling a knight with maximum power |
| Medic! | In a 4-player game, resuscitate each fallen comrade at least once |
| Melee Is Best | Defeat any (end) boss without using any magic |
| The Final Countdown | Survive until 2:30 in a Back Off Barbarian match (Remastered mode) |
| The Traitor | Defeat any boss by playing one of his own minions |
| Traditional | Complete the game using any character |
| Treasure Hunter | Find and dig up ten buried items |

## Original-game differences
- PS3 (13 trophies: 9 bronze, 3 silver, 1 gold) adds **Social Networker** (20 hits in a single Volleyball rally) and **You Are Insane** (complete Insane mode); has no Final Countdown (Back Off Barbarian is Remastered-only).
- Xbox 360 adds **Glork** (win 20 All You Can Quaff Ranked matches); Arena Master was "40 Arena Ranked matches".
- PS4/5 Remastered adds Trophy Crasher (platinum). 16 unique across all versions.

## Vita parity flags
- **Online-only:** Arena Master (and Glork) - need online play; remove or rewrite (e.g. 40 local Arena wins).
- **Multiplayer-only:** Kay Eye Ess Ess (2+ players), Medic! (4 players) - keep only if local/ad-hoc MP exists.
- **Remastered-only:** The Final Countdown - only if Back Off Barbarian is ported.
- Suggested Vita set = the 11 original-shared ones + PS3's Social Networker / You Are Insane, minus online ones.
