## Vita recommendations
- **Remove or re-home Golden Whale** (cross-game/DLC). Suggest the Xbox One Remastered rule (Insane Church Store, 750) if you want 29/29 reachable.
- Pelter/Dragonhead: use the PS3 Insane Store rule (5500 each) - no DLC needed.
- "Animal Handler" completion: Xbox unlocked at Pazzo (26), PS3 after Pelter+Dragonhead (28) - i.e. Whale is not required on those versions. Recommend requiring 28 (or 29 if Whale re-homed).
- Save-edit-only ids (-31, 115, 119, 144, 149, 155, 175) are invalid orb ids with no stats; ignore/clamp them when loading saves.
- Multiplayer note: an orb won't spawn in a level if another player already has it following them.
